# 🏸 Badminton Scoreboard

Aplikasi papan skor digital untuk pertandingan badminton, dibuat menggunakan Flutter. Aplikasi ini memungkinkan pengguna mencatat dan mengatur skor pertandingan secara real-time, mirip dengan papan skor yang digunakan pada pertandingan badminton resmi.

## ✨ Fitur

- Pencatatan skor untuk kedua pemain/tim secara real-time
- Pengaturan skor (tambah/kurangi poin)
- Reset skor pertandingan
- Tampilan skor yang jelas dan mudah dibaca
- Antarmuka sederhana dan responsif

## 🛠️ Teknologi yang Digunakan

- **Flutter** — framework utama untuk pengembangan aplikasi
- **Dart** — bahasa pemrograman
